# 雅迪屏幕助手（重建版）

把手机屏幕实时镜像到雅迪电动车的车机仪表上，支持整屏投屏、单个应用投屏、自定义仪表、壁纸与皮肤。

- 包名：`com.example.bleconnectse.rebuild`
- 支持屏幕：5 寸 800×480、6 寸 1280×640、7 寸 1024×600
- 系统要求：Android 8.0 以上（投屏需要录屏授权与「显示在其他应用上层」权限）

## 下载

到 [Releases](../../releases/latest) 页面下载最新的 `touping-rebuild-vX.Y.Z.apk` 安装即可。

> 国内网络直连 `github.com` 可能超时，下载时如果失败，可把地址换成 jsDelivr 镜像：
> `https://cdn.jsdelivr.net/gh/ydl52/yadea-screen-helper@<tag>/<文件名>`

## 主要功能

- **整屏投屏**：等比留黑边 / 裁切铺满 / 拉伸铺满三种填充方式，投屏中可随时切换；支持 0°/90°/180°/270° 旋转。
- **单应用投屏**：选择某个 App 单独投到车机，导航时车机只显示导航画面。
- **自定义仪表**：自选组件与排版，支持图片/视频背景、字体与粗细调整。
- **壁纸与皮肤**：一键下发到车机，支持历史记录回滚。
- **消息提醒**：微信、QQ 消息弹到车机（含未读角标）。
- **应用内更新**：启动时静默检查 GitHub Release，有新版本可直接下载安装。
